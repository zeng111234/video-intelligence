# IMS 专业口播剪辑升级计划

更新时间：2026-07-29  
当前状态：**暂缓实施，继续使用现有 MPS；不订阅 IMS、不充值、不调用付费接口。**

## 1. 结论

本次升级的目标不是单纯把 MPS 接口替换成 IMS，而是做出一套稳定、克制、适合
知识口播和商业口播的自动剪辑方案。

IMS 负责多轨时间线、字幕、花字、转场、滤镜、音频和模板渲染；系统自己的
ASR、规则和 AI 负责决定剪哪里、标题怎么写、字幕怎么断句、BGM 选哪首。仅更换
渲染供应商而不重做模板和剪辑规则，成片观感不会有明显提升。

计划实施后的默认链路：

```text
上传素材
  → 无费用预检与报价
  → Fun-ASR 转写
  → 粗剪规则生成安全区间
  → qwen-flash 生成受约束的口播方案
  → 浏览器预览与人工复核
  → IMS Timeline 正式渲染一次
  → 成片确认
  → 下载或交接发布
```

## 2. 当前基线

现有 MPS 云端剪辑已经配置完成并可用，适合：

- H.264 转码与 720P/1080P 输出；
- 简单裁剪、片段拼接；
- ASS 字幕烧录；
- 标题图片水印；
- 人声与 BGM 混音。

现有方案的主要限制：

- 标题、字幕、视频和音频缺少真正的多轨时间线编排；
- 标题依赖静态图片，字体、动效和强调词表现有限；
- 字幕排版容易显得笨重，标题和字幕的避让依赖人工坐标；
- 缺少轻微推拉、滤镜、贴纸、花字和更自然的段落过渡；
- MPS 只负责执行参数，不会自动理解内容节奏；
- 自动粗剪和 BGM 选择仍然需要系统自己的算法。

## 3. 产品目标

### 3.1 必须达到

- 面向普通用户仍然保持“一条推荐路径”，不暴露复杂时间线和云参数。
- 首次进入 5 秒内能看懂：上传视频，系统自动给方案，确认后生成。
- 默认只保留一个主按钮：
  - `查看费用并开始分析`
  - `确认字幕与方案并生成`
  - `确认成片并去发布`
- 标题和字幕使用独立安全区域，任何时刻不得互相覆盖。
- 字幕自然断句、字号适中、有描边或阴影，保证明暗背景下都能看清。
- 粗剪优先保证口型和语气连续，不为了缩短时长强行制造跳切。
- AI 根据文案主题从已授权 BGM 库自动推荐，并允许直接试听和更换。
- 付费渲染前展示人民币报价；没有人工确认不得调用 IMS。
- 正式渲染只提交一次，失败和结果未知时不得盲目重复扣费。

### 3.2 暂不包含

- 不做完整的剪映式专业时间线编辑器；
- 不做语义删句、自动改写人声或生成式视频；
- 不做复杂 AE 高级模板和高频炫技特效；
- 不下载或使用来源、商用权利不清楚的字体、音乐和贴纸；
- 不自动发布到第三方平台；
- 不替换或删除现有 MPS，首期保留为稳定兼容方案。

## 4. 专业口播模板

首期只实现一套“专业简洁口播”模板，避免一次开发大量风格。

### 4.1 画面

- 输出比例默认 9:16。
- 720P 输出为 720×1280，1080P 输出为 1080×1920。
- 主体保持在画面视觉中心，不自动做人脸追踪。
- 横屏素材转竖屏时，默认采用主体居中加轻度模糊背景，不粗暴拉伸。
- 长段落可使用 2%～4% 的缓慢推近或推远，禁止频繁抖动和大幅缩放。
- 普通口播不滥用转场；只有真实段落切换或补充素材切换时才使用短淡化。

### 4.2 标题

- 标题独立占用顶部安全区域，不进入人物眼睛、额头和字幕区域。
- 默认最多两行，每行根据画面宽度自动折行。
- 使用已获得商用授权的“极宋”字体文件；授权未确认前使用项目内已授权的
  中文字体，不从网络随意下载替代品。
- 默认使用白字、轻描边、柔和阴影；根据背景亮度自动增加半透明底或调整描边。
- 默认只在开头展示，避免标题全程占据画面。
- 关键词强调使用单一品牌色，不使用多种渐变和厚重立体阴影。

### 4.3 字幕

- 字幕位于底部安全区域，与平台按钮、进度条和标题区域保持距离。
- 默认每屏一至两行，按语义和停顿断句，不把单个词孤立到下一行。
- 字幕采用已授权的“极宋”或同级中文字体，字号由输出档位统一映射。
- 使用细描边与柔和阴影，禁止当前成片中厚重的黑白双层描边。
- 说话期间字幕时间轴必须连续覆盖；无语音时不强行保留上一句。
- 重点词最多突出一到两个，避免全句逐字变色造成廉价感。
- 浏览器方案预览与 IMS 正式成片必须使用同一套字号、行高、位置和断句数据。

### 4.4 粗剪

- v1 只建议处理明确的长停顿，不删除任何有人声区间。
- 默认只考虑不少于 1.5 秒的无语音间隔，并在左右保留保护时间。
- 保护时间先以 0.35 秒为基线，再通过授权样本检查口型、呼吸和语气连续性。
- 切点不得落在音节、吞咽、明显呼吸或动作尚未完成的位置。
- 对不确定切点默认保留原片，不能为了“看起来剪过”而硬切。
- 连续跳切过密时自动合并或关闭该段自动裁停顿。
- 方案预览必须能在浏览器中模拟跳过区间，让用户在付费前听出口型是否连贯。

### 4.5 BGM 与声音

- AI 根据文案主题、情绪、语速和行业标签，从已授权音乐库中推荐一首。
- 推荐结果必须显示推荐理由、授权来源和可试听按钮。
- 允许用户选择“不要 BGM”或手动更换，但不要求每次都人工挑选。
- 人声优先；说话时 BGM 自动降低，停顿和片尾可轻微回升。
- 人声做适度响度统一和峰值保护，不使用会明显改变音色的重度处理。
- BGM 采用淡入、淡出，不在句子中间突然开始或结束。
- 平台音乐只能在权利和使用范围明确时加入，不抓取抖音热门歌曲作为本地素材。

## 5. IMS 接入设计

### 5.1 Provider Adapter

新增独立 IMS Provider Adapter，不把 IMS 调用散落在业务服务中：

- 创建和查询剪辑合成作业；
- 将内部 `EditPlan` 转换成 IMS Timeline；
- 保存 IMS 作业 ID、供应商阶段、费用和实际用量；
- 服务重启后继续查询原作业；
- 查询失败最多自动重试一次；
- 提交结果不明时进入 `outcome_unknown`，禁止自动重提。

现有 MPS Adapter 保留，供应商选择由服务端配置控制，前端不向普通用户展示。

### 5.2 受约束的 EditPlan

qwen-flash 只能从白名单步骤中选择：

- `trim_silence`
- `fit_portrait`
- `title`
- `subtitle`
- `keyword_emphasis`
- `gentle_zoom`
- `background_music`
- `audio_ducking`
- `fade_transition`

服务端必须校验：

- 所有时间范围在素材时长内；
- 不得删除 ASR 标记的有人声区间；
- 标题和字幕不得进入对方安全区域；
- 字体、颜色、特效和转场只能使用批准的模板值；
- 模型不得输出任意 IMS 参数、OSS 地址或供应商任务参数。

### 5.3 状态与人工门禁

继续沿用：

```text
analyzing
→ awaiting_subtitle_review
→ rendering
→ awaiting_output_confirmation
→ ready_to_publish
```

使用 `provider_stage` 细分：

```text
preflight
→ upload
→ transcribing
→ planning
→ awaiting_review
→ submitting_render
→ polling_render
→ downloading_result
```

以下条件全部满足后才能提交 IMS：

- 报价仍在 15 分钟有效期内；
- 用户已经确认本次预计费用；
- 字幕已有明确的人工复核记录；
- 剪辑步骤、标题和 BGM 已保存；
- OSS、IMS 和 RAM 权限检查通过；
- 幂等键未对应其他付费作业。

## 6. 账号和配置准备

等正式开始实施时再处理，不要现在提前购买。

云端需要：

- 开通智能媒体服务 IMS；
- 完成 `AliyunICEDefaultRole` 服务授权；
- 当前服务器 RAM 用户具备 IMS 所需权限；
- IMS、OSS 和输出 Bucket 统一使用华北 2（北京）；
- 继续复用服务器现有 AccessKey，不再创建和传播新密钥；
- 在第一次真实出片前购买最低成本的 IMS 订阅或体验月包。

计划新增的项目配置名称：

```dotenv
VIDEO_EDITOR_RENDER_PROVIDER=mps
ALIYUN_IMS_REGION=cn-beijing
ALIYUN_IMS_OUTPUT_BUCKET=
ALIYUN_IMS_TALKING_HEAD_TEMPLATE_ID=
```

说明：

- 在代码适配完成前，`VIDEO_EDITOR_RENDER_PROVIDER` 保持 `mps`。
- AccessKey 继续读取现有服务端配置，不增加第二份密钥。
- `.env.example` 只放空值和说明，真实值只保存在根目录 `.env`。
- 最终环境变量名称以实现时的官方 SDK 和现有配置结构复核结果为准。

## 7. 分阶段实施

### 阶段 A：免费接入准备

- 新增 IMS Adapter、配置模型和能力检查。
- 新增只读连通性检查，不创建剪辑作业。
- 新增 IMS Timeline 生成和固定响应契约测试。
- 新增报价接口，不调用付费渲染。
- 前端显示“尚未订阅”“权限缺失”“已准备”三种明确状态。

完成标准：无需购买 IMS 也能验证代码结构、请求签名、配置缺失提示和测试。

### 阶段 B：专业口播模板

- 完成标题、字幕、安全区域和字号映射。
- 接入已授权字体文件。
- 实现粗剪保护规则和浏览器跳切预览。
- 实现轻微推拉、段落淡化和人声优先混音。
- 实现 AI 选 BGM、推荐理由、试听和人工替换。

完成标准：浏览器方案预览先通过视觉和听感验收，仍不提交付费任务。

### 阶段 C：受控真实验收

- 用户确认订阅费用后开通最低成本方案。
- 使用 3 条已授权短视频进行首次真实出片：
  - 1 条普通话干净口播；
  - 1 条带噪声或较多停顿；
  - 1 条专有名词或较快语速。
- 每条先出 720P，只渲染一个推荐版本。
- 记录字幕偏差、切点、标题避让、BGM、人声和渲染费用。
- 若模板需要修改，先在浏览器预览修正，避免反复收费渲染。

完成标准：用户明确确认 IMS 成片整体优于当前 MPS 成片，才切换默认供应商。

### 阶段 D：灰度上线

- 通过功能开关只向内部测试账号开放 IMS。
- MPS 保持可选兼容方案，但生产故障不能静默伪装成 MPS 成功。
- 收集至少 10 条授权样本的质量和成本数据。
- 达到验收线后将新口播模板设为默认。

## 8. 测试与验收

### 8.1 自动化测试

- IMS 配置缺失和权限缺失提示；
- 报价公式、过期和价格版本变化；
- 未确认费用时禁止创建作业；
- 幂等创建和结果未知处理；
- Timeline 白名单与时间范围校验；
- 有人声区间不可删除；
- 标题与字幕安全区域校验；
- 720×1280、1080×1920 输出映射；
- 字体不可用时明确阻塞，不偷偷换成不一致字体；
- 单次 ASR 和单次正式渲染；
- 服务重启后的作业恢复；
- 沙箱无真实媒体、无费用、无发布资格。

### 8.2 页面验收

- 1440×900 首屏同时看到素材、预览、方案、费用和唯一主按钮；
- 1024 宽度下自动切换为分区标签或抽屉；
- 页面不向普通用户展示 Timeline JSON、模型名或云参数；
- BGM 可直接试听，AI 推荐理由可理解；
- 浏览器预览与正式成片的字幕、标题位置基本一致；
- 下载、成片确认和发布交接按钮状态真实；
- 前端改动必须在实际运行页面完成核心路径验证，构建通过不能代替页面验收。

### 8.3 成片验收

- 标题、人物面部、字幕和平台操作区域没有遮挡；
- 字幕无明显漏字、错误断句和说话期间的异常空档；
- 没有因为粗剪产生明显口型跳变、吞字或语气断裂；
- BGM 不抢人声，不在句中突入突停；
- 字体、字号、阴影和描边在明暗背景上都清晰；
- 特效克制，同一条普通口播不堆叠多种视觉风格；
- 输出分辨率、帧率和码率符合唯一输出档位；
- 成片费用不超过确认报价的上限；超出时必须阻止提交或再次确认。

## 9. 预算边界

正式实施前重新核对阿里云当时的官方价格。当前计划只保留下列预算原则：

- 在免费代码和浏览器预览未完成前，不购买 IMS；
- 第一次真实验收只购买最低成本的订阅或体验方案；
- 首轮只使用 720P、3 条短视频、每条一个版本；
- 任何付费动作前展示预计总费用并要求一次明确确认；
- OSS、出网、ASR、模型和 IMS 渲染分项展示，不用一个模糊总价隐藏费用；
- 不把失败、处理中或结果未知包装成成功出片。

## 10. 恢复实施时的第一步

重新开始此计划时，不直接购买服务，按以下顺序执行：

1. 复核 IMS 官方 SDK、地域、权限和最新价格。
2. 检查当前 MPS、OSS、ASR 和模型配置，避免重复创建资源。
3. 实现阶段 A 的 Adapter、免费预检和契约测试。
4. 完成阶段 B 的浏览器方案预览。
5. 向用户展示真实预览、订阅费用和三条测试视频的预计总成本。
6. 用户再次明确确认后，才订阅并进行阶段 C 的首次真实出片。
