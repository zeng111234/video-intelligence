# 启动脚本设计审查报告

**审查日期**: 2026-07-20  
**审查人**: Sora Kasugano (UI/交互设计子代理)  
**审查对象**: start.bat 和 scripts/start_all_services.ps1  
**问题类型**: 启动错误影响用户体验

## 1. 核心问题分析

### 主要问题
用户点击 `start.bat` 启动系统时遇到技术性错误，严重影响首次使用体验。

### 错误现象
```
param: <仓库根目录>\scripts\start_all_services.ps1:9
Line |
   9 |  param(
     |  ~~~~~
     | The term 'param' is not recognized as a name of a cmdlet, function, script file, or executable program.
```

### 影响评估
- **用户体验**: 严重受损 - 用户期望一键启动，却看到难以理解的技术错误
- **信任度**: 下降 - 系统稳定性受到质疑
- **使用门槛**: 提高 - 非技术用户可能放弃使用

## 2. 证据检查清单

### 2.1 脚本文件检查
- [x] `start.bat` - Windows批处理文件
- [x] `scripts/start_all_services.ps1` - PowerShell启动脚本
- [x] 脚本编码格式：UTF-8 无BOM（问题根源）
- [x] PowerShell版本兼容性：Windows PowerShell 5.1.19041.6456

### 2.2 环境因素检查
- [x] PowerShell 7 (`pwsh.exe`) 可从当前系统 `PATH` 使用
- [x] Windows PowerShell 5.1 兼容性：版本5.1.19041.6456
- [x] 脚本执行权限设置：使用 `-ExecutionPolicy Bypass`
- [x] 系统区域设置和编码：中文Windows系统

### 2.3 技术问题定位
**根本原因**：PowerShell脚本中`param()`块位置错误
- 脚本第1-3行有代码执行语句（编码设置）
- 第9行才是`param()`块
- PowerShell要求`param()`必须是脚本的第一个非注释语句
- 这导致Windows PowerShell 5.1解析失败

## 3. 修复/优化建议

### 3.1 紧急修复（技术层面）

#### 方案A：修复PowerShell脚本兼容性（推荐）
**问题**：`param()`块必须在脚本最前面，但当前脚本有前置代码
**修复**：重新组织脚本结构

```powershell
# 修复后的脚本结构
param(
    [switch]$SkipBrowser,
    [switch]$SkipHealthCheck
)

# === UTF-8 encoding ===
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8

# Video Intelligence System - Service Startup Script
# Version: 2.0.5
# Date: 2026-07-20

$ErrorActionPreference = "Stop"
$projectRoot = Split-Path -Parent $PSScriptRoot

# ... 其余代码保持不变
```

#### 方案B：提供多种启动方式
1. **简化版批处理** - 不依赖复杂PowerShell语法
2. **图形化启动器** - 双击即可启动的可执行文件
3. **快捷方式** - 预配置好的桌面快捷方式

### 3.2 用户体验优化

#### 错误处理改进
**当前问题**：技术性错误信息直接暴露给用户  
**优化方案**：
```batch
:: 在start.bat中添加错误捕获
if %errorlevel% neq 0 (
    echo.
    echo ========================================
    echo  启动遇到问题，请尝试以下解决方案：
    echo ========================================
    echo.
    echo 1. 右键点击start.bat，选择"以管理员身份运行"
    echo 2. 检查PowerShell执行策略：
    echo    powershell -Command "Set-ExecutionPolicy RemoteSigned -Scope CurrentUser"
    echo 3. 使用简化启动方式：
    echo    双击运行"scripts\launch_app.ps1"
    echo.
    echo 如需技术支持，请截图保存以上信息。
    echo ========================================
    pause
    exit /b 1
)
```
