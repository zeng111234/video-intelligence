# 部署检查清单

## 环境要求

### 系统环境
- [ ] Windows 10/11 或 Linux/macOS
- [ ] Python 3.12+
- [ ] Node.js 18+
- [ ] FFmpeg 已安装并加入PATH

### 端口分配
- [ ] 前端服务端口：1001
- [ ] 后端服务端口：2001
- [ ] Streamlit MVP端口：8501

### 依赖检查
- [ ] Python依赖已安装：`pip install -r requirements.txt`
- [ ] 前端依赖已安装：`npm install`
- [ ] 开发依赖已安装：`pip install -r requirements-dev.txt`

## 服务启动验证

### Streamlit MVP
- [ ] 服务正常启动：`streamlit run app.py`
- [ ] 健康检查通过：`http://localhost:8501/_stcore/health`
- [ ] 页面可访问：`http://localhost:8501`

### FastAPI后端
- [ ] 服务正常启动：`uvicorn app.main:app --port 2001`
- [ ] API文档可访问：`http://localhost:2001/docs`
- [ ] 健康检查端点：`http://localhost:2001/health`

### React前端
- [ ] 开发服务启动：`npm run dev`
- [ ] 页面可访问：`http://localhost:1001`
