# 行业素材储备

这批素材补充了通用商务图标之外的行业语义，共 **175 个 Tabler outline SVG**，并生成同名 PNG 预览。原始英文 ID 保留在各行业目录，中文语义副本放在 `中文命名/`，方便 AI 根据文案选择。

## 已覆盖行业

- `education_exam`：中考辅导、教材、成绩、实验、考试日期、解题思路
- `real_estate_home`：房产、楼盘、户型、装修、门店定位
- `food_retail`：餐饮、饮品、商品、折扣、收款、扫码
- `medical_health`：检查、用药、急救、康复、心理关怀
- `finance_insurance`：金额、收益、利率、报表、风险、保障
- `auto_service`：汽车、保养、维修、充电、车况、门店
- `beauty_parenting`：美妆、护理、母婴、前后对比、焕新
- `legal_corporate`：合同、签名、资质、企业、审核、保密
- `travel_local`：交通、酒店、景点、路线、门票、天气
- `recruiting_career`：招聘、简历、面试、岗位、入职流程
- `ecommerce_delivery`：商品、订单、客服、配送、评价、销售

这些图标是组件原料，不是直接贴在人脸旁的成品贴纸。建议由程序把它们放进数字卡、引线标注、结论徽章、位置标签或画中画说明中，图标面积控制在标签的 15%–25%。
