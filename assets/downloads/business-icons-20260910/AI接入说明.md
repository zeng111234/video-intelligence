# 商务视觉素材接入说明

## 推荐方向

优先使用 Tabler 线性图标作为标签中的辅助图形：图标只占标签宽度的约 15%–25%，文字和数字是主体。颜色只使用品牌主色、白色和黑色，避免把图标单独贴在人物肩膀旁。

建议组合：

| 语义 | 图标 | 建议包装 |
| --- | --- | --- |
| 数字、金额、百分比 | `coin` / `percentage` | 数字大字 + 小图标 + 短促弹入 |
| 地点、距离 | `map-pin` | 横向定位标签 + 数字或地点文字 |
| 风险、否定、取消 | `alert-triangle` / `x` | 红色短标签或划掉线，不得使用成功音效 |
| 结论、完成 | `check` / `clipboard-check` | 绿色或品牌色确认标签 |
| 客户、资料、沟通 | `users` / `database` / `messages` | 轻量引线标注或画中画旁的说明 |
| 工厂、门店、流程 | `building-factory` / `building-store` / `route` | 只在原文明确提到对应对象时使用 |

## 禁止的默认行为

- 不把图标当成独立卡通贴纸随机轮换。
- 不因出现“客户、企业、营销”等词就自动插入工厂、电脑或办公图片。
- 不把 `check` 用在否定、取消或“先别”的句子上。
- 不把 Mixkit 的 MOGRT 文件直接当作 FFmpeg 的透明叠加层；它们只能作为设计参考，或在支持 Premiere 的环境中使用。

## 文件与许可

- `tabler-outline/*.svg`：原始线性 SVG。
- `png/*.png`：同一图标的本地预览格式。
- Tabler Icons 官方项目采用 MIT 许可，完整文本见 `LICENSE`，来源为 `https://github.com/tabler/tabler-icons`。

## 当前状态

本批只完成下载、解码和样式检查，没有修改产品渲染代码，也没有证明某个图标在完整视频中已经好看。接入时应由渲染器生成统一的文字标签、边框、入退场动画和音效，而不是直接把原始 SVG 贴到画面上。
