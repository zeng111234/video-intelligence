# 商务线性图标候选

本目录现在共有 67 个 Tabler Icons outline SVG，并生成了 256px PNG 预览。前 24 个是基础候选，后续追加 43 个商务信息标注图标。官方项目说明这些图标为 MIT 许可、24x24 网格、2px 线条：https://github.com/tabler/tabler-icons 。完整许可见 LICENSE。

## 设计判断

这批不是可直接贴到人脸旁的贴纸。它们适合作为“文字标签/数字卡/引线标注”的小图形：图标占标签面积约 15%–25%，文字占主体，颜色控制为品牌色+白/黑，不使用原始多色 emoji。

建议首批只用：check、x、alert-triangle、map-pin、tag、percentage、chart-line、database、messages、users、building-factory、building-store、arrow-right。追加批次可按 `新增储备索引.json` 的中文用途触发，其他图标不要随机轮换。

当前只完成 SVG/PNG 样式检查；没有改渲染代码，没有接入自动选用，也没有证明任何图标和某句文案的语义匹配。`tabler-contact-latest.jpg` 是追加后的 67 个图标总览。不要把这些图标单独叫作“剪映同款贴纸”。
