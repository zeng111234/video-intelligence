# 剪辑链开源复用边界

更新时间：2026-08-22

本文记录剪辑质量改造的采用边界，避免把一个完整开源项目整套搬进客户安装包。

## 当前可复用的设计

- [video-alchemy](https://github.com/kingbootoshi/video-alchemy)：把逐词时间戳、删句、B-roll 时段和字幕都保存成 JSON，再由 FFmpeg/Remotion 按同一时间轴渲染。我们优先借鉴它的“时间轴是唯一事实来源”和“剪完后重新映射字幕时间”两点。
- [EverythingAI-Pro/ai-video-editor](https://github.com/EverythingAI-Pro/ai-video-editor)：把 B-roll 作为可审核的计划，而不是让模型直接改视频；它也明确区分机械剪辑与需要人工判断的素材选择。其 README 标注原生 Windows 仍不是主要支持目标，因此不直接打包进本项目。
- [dawn-cut](https://github.com/kwakseongjae/dawn-cut)：展示了本地 FFmpeg、字幕校验、画面比例和叠加层的可验证数据契约。它的本地模型和 Electron 依赖较重，只提炼数据校验和样式预设思路。

## 本项目当前真实能力

当前正式轻剪链可以稳定处理：

1. 已确认的原视频和人声；
2. 字幕时间轴、标题和安全的断句预览；
3. 本地原创合成 BGM 或已确认权利的手动上传音乐；
4. 9:16/720p 或 1080p 输出；
5. 独立的产品主图 + 数字人画中画产品讲解版式。

通用任意网站抓取、主体跟踪和自动发布仍然**不是**正式能力；本阶段只开放一个可审计的窄入口：发布模板可按口播主题从官方开源仓库自动取得透明 Material Symbols，并将 SVG 原件、许可证 URL、下载时间和哈希保存到项目素材库。它们进入独立矢量轨道，采用本地淡入/缩放/轻微旋转后再叠加字幕。无法联网、目录变更或素材校验失败时，不阻断出片，自动回退到安全口播画面。

当前允许的来源与边界：

- 透明矢量：Google Material Design Icons / Material Symbols，Apache-2.0；只下载固定官方元数据、SVG 和字体地址，不接受任意搜索结果 URL。
- 主题花字：项目内已有 OFL 字体优先；故事主题可使用 Google Fonts Ma Shan Zheng（OFL-1.1），科技主题使用项目内 Smiley Sans（OFL-1.1）。字体选择只影响发布模板，旧模板仍使用 YaHei。
- 运行时格式：素材库保留原始 SVG 作为证据，同时用官方 Material Symbols 字体渲染透明 PNG 供 FFmpeg 使用；FFmpeg 不直接解码 SVG。

## 下一阶段的低配置实现方案

本阶段采用的轻量发布模板路径，不改变默认路径：

- 系统自动分类为科技、商业、知识、故事或情绪主题，默认最多 3 个透明矢量事件；时间绑定到已确认分镜的 A-roll 段，不让客户手填时间戳；
- 矢量轨道与用户上传 B-roll 轨道分开，默认位于右上安全区，字幕最后渲染，避免遮挡人物和字幕；
- 透明素材动态效果只使用本地 FFmpeg 的淡入、缩放和轻微旋转，不引入付费模型或云端渲染；
- 可继续接入用户上传 B-roll；若用户素材存在，仍按现有授权与审核规则处理，网络矢量素材不冒充真实 B-roll；
- 生图 API 仍是后续可选能力，未配置时不影响本阶段；素材下载、字体下载或 FFmpeg 失败时，保留原时间轴并明确降级。

这样可以逐步得到“口播 + 少量画面切换”的发布级效果，同时不把大模型、Remotion 或额外素材下载器塞进客户电脑。生图只作为明确开启的备用素材来源，不能成为默认依赖。

## 验收门槛

任何 B-roll 实现都必须同时满足：

- 词级字幕与切换时间误差不超过一个字幕帧；
- 音频不被静音、重复或截断；
- 无 B-roll、素材下载失败和 FFmpeg 失败时都能回退原方案；
- 低配置机器在 720p 下不会因为并行渲染耗尽内存；
- 预览、实际导出和发布上传使用同一份时间轴数据。
