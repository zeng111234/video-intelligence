# ASR 准确率基准（2026-07-18）

## 范围

- 视频：`抖音2026718-401279.mp4`，100.33 秒，已确认由用户提供用于本次测试。
- 参考文本：Soundwise 导出的 TXT。该文本本身包含错词，不是人工真值，因此 CER 仅用于同一视频、同一参考下的相对比较。
- 处理：中文、VAD、beam size 5，CPU INT8；不做智能改写。

## 结果

| 方案 | 提示策略 | CER（越低越好） | 数字准确率 | 片段数 | 推理耗时 |
|---|---|---:|---:|---:|---:|
| base | 无 | 25.34% | 62.50% | 87 | 60.47 秒（含媒体处理） |
| large-v3-turbo | 无 | **8.54%** | **75.00%** | 86 | 85.45 秒 |
| large-v3-turbo | 热词 + initial prompt | 35.67% | 42.86% | 4 | 70.11 秒 |
| large-v3-turbo | 仅热词 | 21.63% | 62.50% | 9 | 82.16 秒 |

`large-v3-turbo` 无提示相对当前 `base` 的参考 CER 下降约 66.3%，且保持了完整分段。两种热词方案均出现漏句或重复，因此不得作为当前默认配置。

首次下载 `large-v3-turbo` 加载耗时 420.95 秒；模型缓存后加载约 5.8 秒。模型仓库提示当前 Windows 未启用符号链接，缓存仍可用，但会占用更多磁盘空间。

最终又通过与页面一致的完整服务链路验收：FFprobe 校验、FFmpeg 提取 16kHz 单声道 WAV、`large-v3-turbo` 转写、分段校验和临时文件清理全部成功；100.37 秒视频耗时 84.66 秒，得到 86 个片段。

## 当前决定

- “准确率优先”默认使用 `large-v3-turbo`、不传热词、不传 initial prompt。
- “快速预览”保留 `base`，便于低资源或快速检查。
- 本地热词不暴露到正式页面；待云端引擎具备可验证的热词能力后单独 A/B。
- 云端 ASR 尚未接入：本机未配置腾讯云、火山引擎或 OpenAI 凭证，不能进行真实调用验收。
