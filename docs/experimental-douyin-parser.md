# 抖音单链接解析器（本机实验）

本产品只把它作为“单条、已获授权内容”的本机实验能力：页面不会提供 Cookie 填写、批量下载或绕过验证的功能。

1. 安装后端依赖中的 Playwright Python 包。
2. 保持系统 Chrome 或 Edge 已安装；默认使用 Chrome，可在根目录 `.env` 设置 `DOUYIN_BROWSER_CHANNEL=msedge` 切换。
3. 重启后端。页面会用临时无痕浏览器上下文访问一条公开分享链接，并只读取正常页面加载得到的详情或视频响应。

不会读取浏览器个人资料、Cookie 或登录态，也不会尝试验证码、WAF 破解或无水印地址改写。解析不成功时，爬虫页会显示原因，并由操作者明确确认后才走 OneAPI 回退；该回退按服务商实际账单计费，页面只展示预估值。
