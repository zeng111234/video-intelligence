# VideoInsight 使用说明

适用版本：**0.2.40**  
适用对象：普通客户、内容运营人员和管理员

这份说明只介绍客户日常需要用到的操作。客户只需要安装软件、使用桌面图标并按页面提示操作，不需要额外安装开发工具或打开命令行。

## 一、第一次使用

### 1. 安装或更新

1. 双击 `VideoInsight-0.2.40-Setup.exe`。
2. 选择保存位置。C 盘空间不足时，可以选择 D、E 或其他有足够空间的本地磁盘。
3. 安装完成后，从桌面快捷方式打开 VideoInsight。
4. 已经安装旧版本时，直接运行新安装包覆盖更新即可。更新前请先关闭正在运行的 VideoInsight；客户数据、素材和历史任务会保留。

如果更新后界面看起来仍是旧版，请完全退出软件后重新打开一次，不要只刷新网页。

### 2. 激活登录

在激活页面输入管理员发来的激活码，点击“进入工作台”。激活码会保存在本机，正常情况下重新打开软件不需要再次复制粘贴。

如果提示激活失败：

- 先确认没有多余的 VideoInsight 窗口正在运行；
- 重新打开软件后再试一次；
- 仍然失败时，把提示截图和发生时间发给管理员，不要连续重复点击。

## 二、管理员首次配置

管理员登录后，建议按下面顺序配置一次，普通客户日常不需要重复配置。

1. **系统管理 → 客户激活码**：生成客户激活码、充值或禁用账号。
2. **系统管理 → 管理员账号**：新增管理员、重置其他管理员密码或删除测试管理员。主管理员账号不能由普通管理员重置。
3. **出镜人与声音**：选择已经购买或已授权的形象和音色。默认使用可用的正式形象，不要选择已隐藏的旧测试形象。
4. **素材网站**：打开需要使用的平台登录窗口，在官方页面完成登录，再回到 VideoInsight 点击“刷新状态”。
5. **发布中心 → 管理账号**：分别登录抖音、快手、视频号、小红书和 B 站。每个平台的账号状态独立保存，显示“已连接”后才可以发布。

平台登录、验证码和风控验证必须由账号所有者在官方页面完成，系统不会代替用户绕过验证。

> **重要提醒：**素材浏览器是系统执行采集、原视频核对、转写和部分发布操作的工作窗口。相关任务完成前不要关闭它，也不要结束浏览器后台进程；关闭后平台会显示“未连接”，任务可能失败。误关时重新打开对应平台并点击“刷新状态”即可恢复。

## 三、推荐主流程：智能创作一条龙

客户最常用的是“智能创作”，推荐按以下四步完成：

### 第一步：找素材

1. 打开“智能创作”。
2. 输入关键词，或切换到“视频链接 / 已有文案”。
3. 默认选择“手动挑选”，结果更容易核对。
4. 需要时打开筛选器：平台、视频类型、发布时间、排序方式等。
5. 勾选要使用的素材，点击“手动挑选”或“开始创作”。

> **小提醒：**先确认素材网站显示“已连接”，再开始搜索；筛选条件越多，返回数量越少。抖音、快手、视频号、小红书和 B 站的返回数量不保证相同。

页面显示的是本次实际返回数量。不同平台的数量可能不同，原因包括登录状态、平台限流、搜索词、筛选条件和平台页面变化；没有返回结果时先检查平台是否显示“已连接”。

### 第二步：确认文案和费用

1. 核对原视频、转写内容和生成的标题、正文、话题。
2. 切换平台标签，可分别查看和修改每个平台的发布文案。
3. 页面会显示预计积分和计费说明。确认无误后再点击“确认并开始制作”。
4. 费用不确定时，普通客户不会被静默扣费，按页面提示联系管理员。

不要在任务状态未知时重复点击收费按钮。先点击“刷新实时状态”，确认任务是“处理中、已失败”还是“待确认”。

> **小提醒：**每个平台的标题、正文和话题要分别检查；不要只看当前选中的平台标签。

### 第三步：生成成片

系统会按已确认的形象、声音、字幕和剪辑设置生成视频。生成时间取决于视频时长、清晰度、数字人服务和当前队列，短视频也可能需要几分钟。

生成期间可以在“任务队列”查看进度。请不要关闭软件或重复提交同一个任务；如果页面暂时没有变化，先刷新实时状态。

> **小提醒：**短视频生成也可能需要几分钟。进度不动不等于失败，先看任务状态再决定是否处理。

### 第四步：确认发布

1. 进入“发布中心”，选择已生成的成片。
2. 在平台标签中分别核对标题、正文、话题和封面。
3. 右侧检查每个平台是否显示“已连接”和正确账号。
4. 点击“确认并开始发布”。
5. 如果平台弹出验证码、登录或风险确认，请在该平台官方页面完成后回到 VideoInsight。

系统会按平台分别填充内容。不同平台的字段和限制不同：例如视频号标题较短，B 站需要分区/创作声明，小红书和快手有各自的描述与发布控件。系统只能自动填写和上传平台实际支持的字段，最终发布状态以平台页面为准。

> **小提醒：**看到“已上传”不等于“已发布”。只有平台页面明确显示发布成功，才算完成。

## 四、其他功能

### 专业爬虫

用于单独搜索和筛选素材。它与智能创作使用同一套平台登录状态；如果平台未连接，先打开官方登录窗口并刷新状态。搜索素材本身不等于已经转写、生成或发布。

### 转写复核

可以使用平台链接或上传本地视频。转写完成后先检查人名、数字、标点和断句，再把确认后的文案带入智能创作或数字人流程。

如果快手提示“未能确认视频流属于目标作品”，通常是平台视频源尚未加载、链接已变化或浏览器登录状态失效。刷新一次并重新打开官方页面；仍失败时换一个可正常播放的链接，不要重复付费提交。

### 剪辑成片

用于查看已生成视频、画面比例和清晰度，并确认字幕、标题和配乐。当前版本保留实际可用的轻剪路径，不提供尚未实现的语义删句、智能高光、自动横转竖或任意高级参数。

### 任务队列和消费记录

- “任务队列”查看处理中、待人工确认、已完成和失败任务。
- 右上角积分入口可查看余额和完整消费流水，不只显示最近几条。
- 失败任务是否扣费、是否可重试，以任务详情中的结算说明为准。

## 五、费用和账号安全

- 页面在可能产生费用前显示预计积分，确认后才开始制作或调用服务。
- 预扣费用会按实际结果结算，多余部分按页面规则退回；不要用重复点击来“催进度”。
- 采集和发布建议使用专用账号，不要与个人主账号同时在多台电脑操作。
- 默认发布保护为每个账号每天最多 10 条、两次发布至少间隔 10 分钟。达到限制后需要等待或由管理员按实际业务调整；不要为了赶进度连续重复发布。
- 平台封禁、限流、验证码和内容审核由平台决定，软件不能保证一定不会被限制。发布前请确认内容和账号授权。

## 六、常见问题

### 软件打不开

通常是已有的 VideoInsight 窗口或后台进程还没有完全退出。关闭已有窗口，等待几秒后再从桌面快捷方式打开。仍然打不开时，记录错误提示和发生时间，交给管理员处理，不要自行修改安装目录。

### 页面提示“缺少 API Key”或工作台加载失败

先完全退出软件再重开一次。若仍出现，把错误截图、发生时间和任务名称交给管理员排查；不要自行修改安装目录里的配置文件。

### 素材网站显示“未连接”

在“创作设置/素材网站”中打开对应官方页面，完成登录后回到 VideoInsight，点击“我已登录，刷新状态”。后台浏览器被关闭后，需要重新打开并登录，这是正常的登录会话恢复流程。

采集、转写或发布任务运行中，请保持对应的素材浏览器窗口打开，直到任务显示“已完成”或“已失败”。不要在处理中强制结束浏览器。

### 主页搜索没有结果或平台数量为 0

先确认平台状态为“已连接”，再检查筛选器是否选了过窄的日期、视频类型或排序条件。平台返回数量不保证每次都是 100 条；结果不足时不要把同一个请求连续提交多次。

### 页面卡住不动

先点击“刷新实时状态”，等待一次自动刷新周期。如果任务仍没有变化，返回“任务队列”查看真实状态。只有确认任务失败后才重新提交。

### 发布按钮没有效果

检查三项：已选择成片、平台账号显示“已连接”、平台官方页面没有登录/验证码弹窗。先完成平台页面上的操作，再回到发布中心继续，不要重复点击发布。

## 七、管理员排查信息

客户反馈问题时，请一并提供：

1. 软件版本（系统管理或关于页面可查看）；
2. 发生时间；
3. 当前页面和错误提示截图；
4. 任务名称或任务编号；
5. 使用的平台和账号状态（不要发送密码、激活码或 Token）。

本机日志目录：

```text
C:\Users\<当前用户>\AppData\Local\VideoInsight\data\logs\
```

常用日志文件是 `desktop.log`。日志只发给管理员或技术人员，不要公开上传到群聊或工单之外的地方。

## 八、最短记忆版

**登录平台 → 智能创作找素材 → 手动挑选 → 核对文案和费用 → 确认制作 → 任务队列看进度 → 发布中心逐平台核对 → 最后确认发布。**

遇到异常时遵循：**先刷新一次、看真实状态、确认失败后再重试；不要连续重复收费或发布。**
