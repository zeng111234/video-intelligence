## 功能概览（v2.2.0）

### 核心功能
- **数据仪表盘**: 业务数据可视化（生产趋势、任务分布、热门候选）
- **候选检索**: 三平台（抖音/小红书/视频号）视频搜索
- **批量生产**: 关键词批量生产短视频
- **语音转写**: 支持链接转写和文件上传转写
- **任务中心**: 任务记录查看与管理

### 高级功能（Pro）
- **深度分析**: 趋势分析、竞品分析、内容分布
- **AI文案生成**: 主题输入、风格选择、AI生成文案
- **数字人生成**: 形象录制/上传、TTS/录制/上传音频、视频生成
- **多平台发布**: 一键发布到多个平台
- **关键词爬虫**: 关键词趋势分析

### 系统功能
- **全局搜索**: Ctrl+K 打开，支持页面导航
- **快捷键帮助**: Ctrl+/ 打开
- **通知中心**: 系统通知管理
- **消息中心**: 消息管理
- **个人中心**: 用户信息、账号安全
- **深色/浅色模式**: 主题切换

## 一键启动方式（推荐）

### Windows 用户
```bash
# 双击运行 start.bat 文件
# 或者在命令行执行：
start.bat
```

### PowerShell 用户
```powershell
# 执行启动脚本
.\scripts\start_all_services.ps1

# 跳过浏览器自动打开
.\scripts\start_all_services.ps1 -SkipBrowser

# 跳过健康检查（快速启动）
.\scripts\start_all_services.ps1 -SkipHealthCheck
```
