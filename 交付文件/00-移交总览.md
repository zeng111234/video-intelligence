## 一键启动方式（推荐）

### Windows 用户
```bash
# 双击运行 start.bat 文件
# 或者在命令行执行：
start.bat
```

### PowerShell 用户
```powershell
# 执行启动脚本
.\scripts\start_all_services.ps1

# 跳过浏览器自动打开
.\scripts\start_all_services.ps1 -SkipBrowser

# 跳过健康检查（快速启动）
.\scripts\start_all_services.ps1 -SkipHealthCheck
```
