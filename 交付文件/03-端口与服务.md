# 端口与服务

## 已登记端口
| 端口 | 服务 | 说明 |
|------|------|------|
| 1001 | React 前端 | 前端界面，Vite 开发服务器 |
| 2001 | FastAPI 后端 | REST API 服务，提供 Swagger/ReDoc 文档 |

## 预览入口
- React 前端：http://localhost:1001
- FastAPI 后端：http://localhost:2001
- API 文档（Swagger）：http://localhost:2001/docs
- API 文档（ReDoc）：http://localhost:2001/redoc

## 服务与依赖说明

### 数据库
- **开发环境**：SQLite，数据库文件位于 `data/video_intelligence.db`，开箱即用无需配置
- **生产环境**：PostgreSQL（可选），需创建 `.env` 文件配置连接信息
- 数据库迁移脚本位于 `database/migrations/` 目录

### 外部依赖
- **FFmpeg**：视频处理必需，需单独安装
- **faster-whisper**：本地语音识别引擎，Python 依赖自动安装
