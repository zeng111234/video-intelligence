# 代码结构

> 源代码不重复复制进 `交付文件/`，请直接把整个项目目录交给同事，这份文件只负责告诉对方该从哪里开始看。

## 项目根目录结构
```
video/
├── app.py                    # Streamlit 主应用入口
├── app_pages/                # Streamlit 页面模块
├── src/                      # 核心业务逻辑（服务、模型、适配器）
├── project/
│   ├── frontend/             # React 前端工程（端口 1001）
│   └── backend/              # FastAPI 后端工程（端口 2001）
├── database/                 # 数据库脚本与迁移
├── data/                     # 数据文件（SQLite 数据库等）
├── tests/                    # 测试代码（~290 个用例）
├── scripts/                  # 启动脚本与工具
├── doc/                      # 项目文档（详细设计、交付报告）
├── docs/                     # 项目文档（归档、指南）
├── prototype/                # 产品原型
├── references/               # 参考资料
├── utils/                    # 工具函数
├── start.bat                 # Windows 一键启动脚本
├── requirements.txt          # Python 依赖
└── README.md                 # 项目说明文档
```

## 前端相关目录
- `project/frontend/`：React 18 + TypeScript + Vite + Ant Design

| 页面 | 路由 | 说明 |

| TranscriptionPage | `/transcription` | 语音转写（链接/文件） |

| AnalyticsPage | `/analytics` | 深度分析（Pro） |

## 后端相关目录
- `project/backend/`：FastAPI + Pydantic
- `src/`：核心业务逻辑（服务层、数据层、适配器层）

## 数据与配置目录
- `database/`：SQL 初始化脚本、迁移框架（MigrationRunner）
- `data/`：SQLite 数据库文件、运行时数据
- `scripts/`：启动脚本（start_all_services.ps1）、基准测试工具

## 测试目录
- `tests/`：pytest 测试用例（19 个测试文件，约 290 个用例）
- `project/backend/tests/`：后端 API 测试（43 个用例）

## 文档与设计目录
- `doc/`：详细设计文档、交付报告
- `docs/`：归档文档、开发指南
- `prototype/`：产品原型（decision-guide.html、b2b-optimization/）

## 关键配置文件
- `project/frontend/package.json`：前端依赖配置
- `project/backend/requirements.txt`：后端依赖配置
- `requirements.txt`：Python 全局依赖
- `pytest.ini`：测试配置
- `.gitignore`：Git 忽略规则
