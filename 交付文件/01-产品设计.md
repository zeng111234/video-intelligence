# 产品设计

## 项目名称
短视频热点洞察与智能生产系统

## 项目一句话说明
面向品牌营销团队的短视频热点发现、候选管理、批量内容生产与多平台发布系统。

## 当前产品形态
这是一个前后端分离项目，建议同事按“前端 → 后端 → 依赖服务”的顺序理解和接手。

## 当前已实现范围
- 前端目录：project/frontend
- 后端目录：project/backend
- 预览入口：
  - React 前端：http://localhost:1001
  - FastAPI 后端：http://localhost:2001
  - API 文档：http://localhost:2001/docs / http://localhost:2001/redoc
  - Streamlit MVP：http://localhost:8501

## 已实现功能（v2.2.0）

### 核心功能
1. **数据仪表盘** - 业务数据可视化（生产趋势、任务分布、热门候选）
2. **候选检索** - 三平台（抖音/小红书/视频号）视频搜索与管理
3. **批量生产** - 关键词批量生产短视频流水线
4. **语音转写** - 支持链接转写和文件上传转写
5. **任务中心** - 任务记录查看与管理

### 高级功能（Pro）
1. **深度分析** - 趋势分析、竞品分析、内容分布
2. **AI文案生成** - 主题输入、风格选择、AI生成文案
3. **数字人生成** - 形象录制/上传、TTS/录制/上传音频、视频生成
4. **多平台发布** - 一键发布到多个平台
5. **关键词爬虫** - 关键词趋势分析

### 系统功能
1. **全局搜索** - Ctrl+K 打开，支持页面导航
2. **快捷键帮助** - Ctrl+/ 打开
3. **通知中心** - 系统通知管理
4. **消息中心** - 消息管理
5. **个人中心** - 用户信息、账号安全
6. **深色/浅色模式** - 主题切换
