# 短视频热点洞察系统 - B端优化原型

## 项目概述

本原型是短视频热点洞察与智能生产系统的B端优化版本，旨在提升产品的专业感、数据可视化能力和付费转化率。

## 快速开始

### 查看原型

1. **直接打开HTML文件**：
   - 双击 `dashboard-prototype.html` 文件
   - 在浏览器中查看完整原型

2. **本地服务器运行**（推荐）：
   ```bash
   # 使用Python启动简单HTTP服务器
   cd prototype/b2b-optimization
   python -m http.server 8080
   
   # 或者使用Node.js
   npx serve .
   ```
   然后访问 http://localhost:8080/dashboard-prototype.html

### 功能特性

#### 1. 数据仪表盘
- **关键指标卡片**：今日热点数、生成文案数、发布成功率、Token消耗量
- **趋势图表**：Token消耗趋势（支持7天/30天/90天切换）
- **平台分布**：抖音、小红书、视频号占比统计
- **近期任务**：最近的任务执行情况
- **热门候选**：热度最高的候选内容

#### 2. 付费转化路径
- **侧边栏升级入口**：底部固定的升级卡片
- **套餐对比弹窗**：Free vs Pro功能对比
- **Pro功能标识**：导航菜单中的金色PRO徽章
- **限时优惠提示**：价格展示和优惠信息

#### 3. 效率工具栏
- **批量操作**：批量搜索、批量导出、一键生成文案
- **快捷功能**：批量剪辑、批量发布
- **AI智能优化**：Pro功能，带光晕动画效果

#### 4. 深色模式
- **一键切换**：顶部导航栏的月亮/太阳图标
- **完整适配**：所有组件都支持深色模式
- **持久化存储**：记住用户的主题偏好

#### 5. 响应式设计
- **桌面端**：完整布局，多列网格
- **平板端**：自适应布局
- **移动端**：单列布局，侧边栏隐藏

## 设计规范

### 色彩系统
- **主色调**：蓝紫渐变 (#6366f1 → #8b5cf6)
- **功能色**：成功(#10b981)、警告(#f59e0b)、错误(#ef4444)
- **中性色**：灰色系 (#f8fafc → #0f172a)

### 字体系统
- **主字体**：Inter + Noto Sans SC
- **字号层级**：12px/14px/16px/20px/24px/32px

### 间距系统
- **基准网格**：4px
- **常用间距**：8px/12px/16px/20px/24px/32px

### 圆角系统
- **小圆角**：8px（按钮、输入框）
- **中圆角**：12px（卡片、弹窗）
- **大圆角**：16px（大卡片）

## 自定义配置

### 修改主色调
在CSS变量中修改主色调：
```css
:root {
    --primary-500: #your-color;
    --primary-600: #your-color;
    --primary-700: #your-color;
}
```

### 修改字体
在CSS变量中修改字体：
```css
:root {
    font-family: 'Your Font', 'Noto Sans SC', sans-serif;
}
```

### 修改间距
在CSS变量中修改间距基准：
```css
:root {
    --space-1: 4px;
    --space-2: 8px;
    /* ... */
}
```

## 常见问题

### Q: 原型无法正常显示？
A: 确保使用现代浏览器，并检查是否启用了JavaScript。

### Q: 深色模式不生效？
A: 检查浏览器是否支持CSS变量，并确保JavaScript正常执行。

### Q: 响应式布局有问题？
A: 检查浏览器窗口大小，并测试不同设备尺寸。

### Q: 如何修改数据？
A: 编辑HTML文件中的静态数据，或连接后端API获取动态数据。
