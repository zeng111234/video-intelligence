## 使用说明

1. 直接打开HTML文件即可查看原型
2. 所有原型均为单文件实现，包含完整的HTML、CSS和JavaScript
3. 原型支持PC、平板和手机等多种设备
4. 交互功能完整，可进行真实操作体验

## 设计规范

- 视觉风格：高保真、现代、简洁、有质感
- 配色方案：统一、层次清晰
- 交互效果：hover、active、点击反馈、过渡动画
- 响应式：自适应不同屏幕尺寸
- 代码规范：结构语义化、可维护、可扩展
