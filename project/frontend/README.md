# 前端工程

React + Vite + Ant Design + TypeScript 前端，默认端口 1001。

## 页面

- `/candidates` — 候选检索（爆火视频搜索）
- `/pipeline` — 批量生产流水线
- `/transcription` — 转写任务
- `/tasks` — 任务中心
- `/admin` — 系统管理

## 启动方式

```powershell
npm install
npm run dev
```

## 默认端口

- 开发服务端口：1001
- API 代理目标：http://localhost:2001（Vite proxy）

## 技术栈

- React 18
- TypeScript
- Vite 5
- Ant Design 5
- React Router 6
